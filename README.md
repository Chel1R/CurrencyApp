Currency Converter App

An offline-first Android application for real-time currency conversion, exchange rate tracking.

* **Real-Time Currency Conversion:** Instantly convert values between currencies.
* **Offline-First Support:** Caches exchange rates locally using **Room** to ensure the work without internet.
* **Modern Material 3 UI:** Clean, reactive, and fully accessible user interface built entirely with **Jetpack Compose**.
---
## 🛠️ Tech Stack & Libraries

* **Language:** [Kotlin](https://kotlinlang.org/)
* **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material Design 3)
* **Dependency Injection:** [Hilt](https://dagger.dev/hilt/)
* **Local Database:** [Room](https://developer.android.com/training/data-storage/room) (for storing rates offline)
* **Networking:** [Retrofit 2](https://square.github.io/retrofit/) + [Moshi](https://github.com/square/moshi) / [OkHttp](https://square.github.io/okhttp/)
* **API Source:** [Frankfurter API](https://www.frankfurter.app/)
